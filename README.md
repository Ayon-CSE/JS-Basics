# 🚀 JS Basics - Complete JavaScript Learning Repository

A comprehensive, well-organized JavaScript learning resource covering fundamentals to advanced concepts with hands-on projects.

### **Fundamentals**
- Variables, Data Types & Conversion
- Operators & Comparison Logic
- Control Flow & Loops
- Functions & Arrow Functions
- Scope & Closures
- IIFE, Execution Context

### **Core Concepts**
- Arrays & Array Methods (Map, Reduce, forEach)
- Objects & Prototypes
- JSON Handling
- Promises & Async Programming
- Date & Time

### **Advanced Topics**
- Object-Oriented Programming (Classes, Inheritance, Static Methods)
- Property Descriptors & Getters/Setters
- Prototype-Based Inheritance
- Call, Apply & Bind Methods
- DOM Manipulation & Events

### **Interactive Projects**
- 🎮 **Guess a Number** - Game with logic
- 🎨 **Color Scheme Switcher** - DOM & CSS integration
- ⏰ **Digital Clock** - Real-time updates
- 💪 **BMI Calculator** - Practical utility
- 🎹 **Keyboard Event Tracker** - Event handling
- 🌈 **Unlimited Colors** - Dynamic generation

### **Competitive Programming**
- Codeforces & AtCoder Submissions (C++)
- Algorithm implementations & solutions

## 🎯 Perfect For
- Beginners learning JavaScript fundamentals
- Intermediate learners mastering OOP & advanced concepts
- Interview preparation
- Building a strong JavaScript foundation
